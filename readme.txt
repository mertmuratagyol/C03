42 C Piscine - C03

This repository contains my solutions for the C03 project of the 42 Kocaeli C Piscine.

About the Project

The C03 project focuses on string manipulation, comparison, and searching algorithms in C. It implements custom versions of standard C library string functions, exploring how strings are compared, joined, located, and concatenated while strictly adhering to the Norm coding standards.

Exercises

* Ex00: Compares two strings lexicographically (ft_strcmp.c)
* Ex01: Compares up to n characters of two strings (ft_strncmp.c)
* Ex02: Concatenates two strings (ft_strcat.c)
* Ex03: Concatenates up to n characters of a string (ft_strncat.c)
* Ex04: Locates a substring within a string (ft_strstr.c)
* Ex05: Appends a string with a specified total buffer size (ft_strlcat.c)

Technologies & Rules

* Language: C
* Compiler: gcc (with -Wall -Wextra -Werror flags)
* Standard: 42 Norm (Norminette compliant)
